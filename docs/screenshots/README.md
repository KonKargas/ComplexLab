# ComplexLab screenshots

Add real screenshots from a running ComplexLab instance to this folder using these names:

- `dashboard.png`
- `complex-number-calculator.png`
- `matrix-calculator.png`
- `complex-number-visualizer.png`
- `matrix-visualizer.png`
- `calculation-history.png`

Use a consistent browser viewport and crop out personal information. For the history page, use only disposable demo calculations. When the images are ready, uncomment the screenshot image lines in the root README.
